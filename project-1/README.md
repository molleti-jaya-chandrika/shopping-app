PROJECT 01: LINUX SERVER INFORMATION REPORT

Environment:
AWS EC2 - Amazon Linux 2023

Objective:
To automate Linux server information collection
using a Bash script.

Tools:
Linux, Bash Scripting, AWS EC2

Information Collected:
1. Date and Time
2. Hostname
3. Operating System
4. Server Uptime
5. CPU Cores
6. Memory Information
7. Disk Information

Script:
server-report.sh

Generated Report:
server-report.txt

Execution:
chmod +x server-report.sh
./server-report.sh

Result:
Successfully generated server information report.
